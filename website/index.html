SPlayer for Android Fork

一个基于 SPlayer for Android 的个人 Fork，记录一些 Android 端的修改和尝试。

主要是根据自己在 Android 上的使用需求，做一些界面、播放、歌词和本地音乐相关的调整。

主要修改

目前主要改动集中在 Android 端的界面、播放、歌词和本地音乐等部分。

Android 端
做过一些手机、平板、横屏和安全区相关的布局调整：手机竖屏与横屏分别排版，旋转后恢复原状态，底栏和悬浮播放栏避开系统手势区与刘海。
歌词
包含逐字歌词、翻译、罗马音、歌词偏移以及悬浮歌词相关功能。桌面歌词支持拖动、锁定穿透、自动字号，无操作后控件自动淡出。
本地音乐
支持本地歌曲扫描，以及 LRC / TTML 歌词匹配，可以放在歌曲同目录，也可以指定独立歌词目录，并选择用本地歌词覆盖在线歌词。
播放相关
包含 ExoPlayer、后台播放、通知栏控制、MediaSession 等 Android 相关修改，另外有弱网重试、断点恢复、渐入渐出和允许与其他应用同时播放的选项。
在线与远程来源
在线音乐使用网易云，远程曲库支持 WebDAV、Jellyfin、Navidrome、Emby、Subsonic / OpenSubsonic，另外接入了 Last.fm 的播放记录。
安装包与应用内更新
按 arm64-v8a / armeabi-v7a / x86_64 / x86 分架构打包。应用内更新会按设备架构选择对应安装包，并在安装前校验文件摘要、包名、版本和签名。

关于项目

这是一个基于 SPlayer for Android 的个人 Fork，主要记录一些 Android 端的修改和尝试。

项目主要用于个人学习、实践，以及处理自己使用 Android 版本时遇到的一些问题。

开发过程中也使用了 AI 工具辅助分析、修改和测试。

更新没有固定计划，也不承诺长期维护。

常见问题

应该下载哪个版本？

多数现代 Android 手机选择 arm64-v8a。2015 年前后的老设备通常是 armeabi-v7a，x86_64 和 x86 基本只用于模拟器。

最低支持什么系统？

Android 10（API 29）。更早的版本没有计划去实现支持。

这是官方 SPlayer 吗？

不是。这是个人维护的社区非官方 Fork，与 SPlayer 及 SPlayer for Android 上游不存在官方隶属、合作或授权背书关系。

会长期更新吗？

没有固定更新计划，也不承诺长期维护。改动了什么会记在 CHANGELOG 里。

Windows 可以使用吗？

当前这个 Fork 主要维护 Android 版本，仓库里已经不包含桌面端打包链路。桌面版本请查看上游 SPlayer。

通知栏控制器不显示？

先在「设置 → 播放」中打开「通知栏音乐控制器」，再在系统设置里允许 SPlayer 发送通知。Android 13 及以上首次启用时会弹出通知权限请求。

本地歌词不显示？

在「设置 → 本地与缓存 → 本地歌词覆盖在线歌词」中添加歌词目录。歌词可以命名为 歌曲ID.lrc、歌曲ID.ttml，带 ncmMusicId 元数据的 TTML 也能自动匹配；与音频同目录同名的歌词文件同样会被识别。
